# Lesson 19 — DIY

Practice in `lab/app.py` using `bash diy.sh`.

## Your Exercise

1. Use `argparse` to accept a required positional `service` name.
2. Add optional `--port` with `type=int` and default `8080`.
3. Print `service:port`.
4. Test `--help`, a valid port, and a nonnumeric port.

Optional: add a `--enabled` flag with `action='store_true'`.
