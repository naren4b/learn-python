# Lesson 16: DIY

Use the existing local scratch file `lab/app.py`.

## Your Exercise

1. Define a `Server` class with `name` and `port` in `__init__`.
2. Store these using `self.name` and `self.port`.
3. Implement `describe()` to return the name and port.
4. Create two servers and print each description.
5. Optional: add a boolean health attribute.

Reference: [16_oop.py](16_oop.py).
