# Day 6: Do it yourself

From the repository root run `bash diy.sh`, then run `python lab/app.py` after saving.

## Pseudocode
```text
CREATE list of three latency values
APPEND another value
PRINT first and last items
PRINT item count
CALCULATE total and average
PRINT total and average
```

## Your Exercise
1. Create `latencies = [120, 130, 140]`.
2. Append `160`.
3. Print the first and last values using indexing.
4. Print the count using `len()`.
5. Calculate and print total and average; format the average to two decimal places.
6. Append `200` and see what changes.

For guidance see [the reference](06_lists.py). No need to commit local practice files.
